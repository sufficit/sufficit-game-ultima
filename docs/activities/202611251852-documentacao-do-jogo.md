# Atualização da documentação do Ultima

## Investigação

O documento do projeto descrevia o marco inicial. A implementação e os guias
técnicos já documentavam a câmera orbital, a Oficina, a Guardiã, as salas e a
API ASP.NET Core.

## Alterações

- A [visão do jogo](../../PROJECT.md) descreve o ciclo e o estado atual
  do protótipo. O marco inicial permanece no histórico.
- O [guia do jogador](../USAGE-JOGO.md) explica controles, coleta,
  conversas, diagnósticos, convites e exploração individual.
- O [índice](../README.md) e a [entrada do repositório](../../README.md)
  apontam para o guia, a arquitetura e a documentação técnica.

## Validação e entrega

Os controles, rótulos e parâmetros foram confrontados com a implementação.
O verificador de Markdown da skill game-docs passou sem erros nem avisos.
A versão publicada do jogo respondeu no GitHub Pages e a API retornou
estado saudável. [Jogo](https://sufficit.github.io/sufficit-game-ultima/)
